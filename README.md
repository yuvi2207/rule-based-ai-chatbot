# rule-based-ai-chatbot

A simple chatbot made using Python.
This project uses basic rule-based responses to answer user questions.
## Features
* Greets user according to time
* Answers basic questions
* Gives motivational replies
* Exits when user types `bye`
## Technologies Used
* Python
* Functions
* Dictionary
* Loops and Conditions
## How to Run
```bash id="k9m2x1"
python main.py
```
## Example
```text id="h4n7p3"
You : hello
Bot : Hi there!
You : motivate me
Bot : Keep learning daily 💪
```
